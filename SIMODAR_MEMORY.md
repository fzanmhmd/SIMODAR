# SIMODAR Project Memory

## Identitas
- Nama aplikasi: SIMODAR
- Kepanjangan: Sistem Informasi Mobile Unit Donor Darah
- Fokus aplikasi: sistem informasi untuk layanan mobile unit donor darah.

## Logo
- Logo utama menampilkan mobil donor darah berwarna merah dengan ikon tetes darah putih di sisi kendaraan.
- Terdapat lampu/sirene di bagian atas mobil.
- Teks brand: `SIMODAR` dengan gaya tebal, modern, geometris, dan berwarna merah.
- Kesan visual: cepat, medis, donor darah, bersih, modern, dan tepercaya.

## Warna Brand
- Merah utama: warna dominan logo, digunakan untuk brand, tombol utama, status penting, dan aksen.
- Putih: latar/logo negatif, digunakan untuk area bersih dan kontras.
- Rekomendasi palet awal:
  - Primary Red: `#E91419`
  - Deep Red: `#B90F14`
  - Soft Red: `#FDE7E8`
  - White: `#FFFFFF`
  - Text Dark: `#1F2933`
  - Muted Gray: `#6B7280`

## Arah Desain
- Tampilan aplikasi sebaiknya bersih, modern, profesional, dan mudah dipakai.
- Gunakan merah sebagai aksen utama, bukan seluruh layar agar antarmuka tetap nyaman.
- UI cocok untuk admin/petugas donor darah: informatif, rapi, mudah dipindai, dan efisien.
- Komponen penting yang mungkin dibutuhkan:
  - Dashboard
  - Data jadwal mobile unit
  - Data pendonor
  - Data stok darah
  - Data lokasi kegiatan donor
  - Form pendaftaran donor
  - Login/admin
